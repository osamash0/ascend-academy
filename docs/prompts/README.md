# Session prompts

Reusable prompts for a Claude Code (or Codex) session. Paste one into a fresh session; each says what branch to use and what "done" means.

| File | Use it when | Written |
|---|---|---|
| `2026-10-30-documentation-reset.md` | The docs have drifted from the code: regenerate CLAUDE.md, the inventory, runbooks and the screen-text audit. | 2026-10-30 |
| `V4_SCENARIO_TESTING_PROMPT.md` | Before a deploy: walk the v4 rooms as a learner, an owner and a stranger with a link, and file what breaks on the punch list. | 2026-10-24 |
| `AUDIT_SESSION_PROMPT.md` | A browser-driven audit of the whole app, every route, both roles. Produced `APP_AUDIT_REPORT.md` on 2026-08-17. Older than v4; adapt the route list first. | 2026-08-17 |
| `OVERNIGHT-PROMPT-ROADMAP-PHASE2.md` | Historical. The overnight run that built roadmap phase 2 (planner, search, professor actions). Keep for the method, not the content. | 2026-09-05 |

Prompts that live next to the code they drive stay there: `src/features/spaces/BUILD-PROMPT.md`, `READER-PROMPT.md`, `OVERNIGHT-PROMPT.md` (the v4 build sessions of 2026-08/09).
