# v4 glossary — English ↔ German

*Decided 2026-10-11 (Abi: "go with your recommendations"). Every v4 string uses these words. The register rules are in `docs/BRAND_VOICE.md` ("German register"): **du, never Sie**; gender-inclusive forms; no translated exclamation marks; "wir" in errors.*

## The nouns

| English | German | Never |
|---|---|---|
| Space | **Space** (der Space, die Spaces) | Raum, Bereich, Kurs |
| Lesson | **Lektion** (die Lektion, die Lektionen) | Vorlesung, Kurs, Einheit |
| page | **Seite** | Folie |
| idea | **Idee** | Konzept (in UI copy) |
| Material | **Material** | Dokument, Datei (in UI copy) |
| Library | **Bibliothek** | |
| Studio | **Studio** | |
| people (who maintain a Space) | **Leute, die den Space pflegen** | Dozent (without :in), Professor |
| student | **Studierende** (pl.), **Studierende:r** (sg.) | Student, Studenten |

## Stays as it is
